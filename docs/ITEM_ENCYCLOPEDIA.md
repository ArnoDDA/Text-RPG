# 物品系统：类别、等级与具体实例

物品系统只维护稳定的判断框架，不试图预先列出世界里所有可能出现的名称。其结构是：

`物品章节 → 基础类别 → 等级规则 → 当前时间线中的具体物品`

## 基础类别

`data/item_types.json` 定义九个章节下的 370 个基础类别，其中包括 68 个武器类别、47 个防具类别和 35 个衣着类别。武器、防具和衣着的基础条目按单一形制记录，不再把两个独立形制合并在同一名称中；防具与衣着共享“穿戴与防护”上层分组，并保留各自的子类。工具、行旅、食物、医药、材料和珍宝也按可检索的具体形制拆分。`data/item_type_rules.json` 定义各类别的通常用途与真实限制。

因此，单手剑与双手大剑分开，船只与飞行器具分开，主食与蔬菜、肉类分开。地区、组织、制造者、颜色、装饰和普通工艺差异不单独建立类别；它们属于具体物品的来源与特征。

## 等级

类别与等级是两个独立字段。类别回答“它是什么”，等级回答“它有多容易取得、需要怎样的工艺与来源”。等级不自动等于战力、售价或特殊能力。

| 等级 | 判断边界 |
| --- | --- |
| 普通／常见 | 能够稳定制作、种植、采集或流通，普通渠道可以接触 |
| 稀有 | 需要较高工艺、有限产地、专业资格或稳定特殊性质 |
| 罕见 | 只有少数工坊、组织或环境能够稳定提供，取得与维护条件严格 |
| 传说 | 已知世界中极少数真正存在、拥有独立名称、来历与历史记录的具体物品 |
| 神话 | 几乎不可复现、原则上仅此一件，并与神明、法则或世界级事件直接相关的具体物品 |

普通、稀有与罕见可以用于一般物品实例。传说和神话只能用于已经确立的具体具名物品，不能作为普通制式批量生成，也不能从“无敌”“远古”“神圣”等名称推断。

等级同时约束出现环境。普通街道、住宅、酒馆、一般商店、普通卫兵与小股匪徒主要出现普通物品；专业商店、知名工匠、精锐部队、持证魔法市场与富裕收藏才有合理机会出现稀有物品；王室军械库、大法师据点、龙巢、封印遗迹和大型势力宝库等受限来源才可能稳定支持罕见物品。任务难度、敌人强弱和戏剧性本身都不是提高物品等级的依据。

叙事者记录非普通物品时，必须同时给出世界内已经成立的出现渠道与具体依据。传说物品需要可追溯的专名、历史与重要经历；神话物品还需要既有设定证明它与神明、世界法则或世界级事件直接相关。它们可以在因果充分的故事中自然出现，不需要玩家充当世界设定审核者。

如果一件物品的来历与性质尚未查明，背包只显示“未鉴定”，不会向玩家展示内部校验或临时等级。后续通过使用、调查、鉴定或史料取得证据后，记录会自然揭示等级。背包中的“记录”操作只负责保存已经发生的持有变化，不代表玩家决定物品是否真实存在。

百科不会在每个类别下重复这张通用表。`data/item_rarity_contexts.json` 会按照武器、防具、衣着、工具、行旅、食物、医药、材料和珍宝各自的生产方式，为每个基础类别生成五档判断说明与少量示例物品：普通 4 个、稀有 3 个、罕见 2 个、传说 2 个、神话 1 个。示例会使用具体形制和自然的物品名称，例如“制式弩炮”“精制佩剑”或“断潮者”，不再把“北门卫队·重型武器”这类内部类别标签直接展示给玩家。这里列出的名称只是帮助理解等级的实例，不是世界中全部物品的清单；武器的传奇与神话示例会附上一句简短事迹，帮助玩家理解它们为什么是极少数具名传承，而不是普通制式的升级版。示例不代表已经写入当前故事；传说和神话示例使用具名形式，不能因为看到名称就推断该物品已经存在。

## 具体实例

故事和玩家可以自由命名物品。背包保存玩家实际遇到的那一件，包括名称、基础类别、等级、数量、持有者、状态、产地、材质、外观、历史与已证实性质。

例如“月蚀礼剑”可以记录为：

- 基础类别：单手剑
- 等级：罕见
- 来源：王冠城某工坊
- 材质：已确认的合金
- 已知性质：只记录故事中得到证实的部分

百科不需要先收录“月蚀礼剑”。系统通过类别和等级理解它，名称与具体经历仍完整保留在当前时间线。

## 运行边界

新物品会根据明确的名称和描述提出基础类别建议；无法可靠判断形制时，背包会暂时等待补充记录。等级来自故事中已经成立的来源、工艺和历史证据，而不是玩家审核或角色强度。叙事者只能提出背包记录，不会替玩家操作本地界面；玩家点击“记录到背包”只是保存已经发生的持有变化，不参与裁定物品是否存在。

物品类别由本地确定性规则提供，不作为数百条百科正文送入每回合上下文。物品相关的生产、交通、市场、制度与地区生活仍由 `data/world_bible_material_culture.json` 中的世界观条目描述。

施法媒介、法器、卷轴、结界器、魔法器具、仪式器具、飞行器具、传送门径、药剂、附魔材料和魔法遗物等类别还会显示“与能力的关系”。施法媒介只辅助角色已有能力，法器则拥有独立术式或在满足条件时赋予能力。关系说明会进一步明确能力属于角色、一次性载体、独立器具还是装备赋能，以及失去物品后是否仍然有效。它不创建具体物品，也不把物品等级直接换算成能力强度。
