# Secret Fire 七项属性与世界裁定规则

> 百科规则文档
> 适用范围：人物、非人生物、超凡存在及需要能力比较的世界行动。

## 一、基本原则

属性不是角色的完整说明，也不是职业、身份或综合等级。它只负责给世界提供一组稳定的能力边界，防止出现普通人徒手压倒古龙之类缺乏现实条件的结果。

- 七项属性统一使用 `1–100+`。
- 每相差 `10` 点，代表跨越一个明显能力门槛。
- 差距达到 `20` 点时，使用同一能力正面对抗基本无法逾越；较弱一方必须改变方法、目标或现实条件。
- 不计算属性总和，不设置“综合战力”，也不因种族、身份或地位而自动全项提高。
- 不使用骰子。接近层级的结果由行动方式、专业、环境和既有事实决定。
- 人物可能在某一项达到神话层级，同时在另一项接近普通人。
- `100+` 仍可继续计数，但通常属于神明、法则或玩家正常接触范围之外的存在。

## 二、七项属性

| 属性 | 核心含义 | 明确不包括 |
| --- | --- | --- |
| 体魄 | 身体的力量、耐力、生命力、抗性与自然恢复能力 | 动作技巧、特殊免疫、装备防护 |
| 身手 | 反应、协调、平衡、精细控制和动作效率 | 体力、感官、已经学会的专业技巧 |
| 感知 | 获取外界信息、警戒、追踪、辨别异常和方向判断 | 知识、逻辑推理、读心或不存在的感官 |
| 智识 | 学习、记忆、推理、规划、理解复杂事物和创造方法 | 已经掌握的专业知识、精神稳定、社交影响力 |
| 心性 | 专注、自制、勇气、信念、精神稳定和维持自我 | 身体耐伤、知识、道德善恶 |
| 魅力 | 外貌、声音、气质、存在感以及天然的情绪感染力 | 谈判技巧、身份权力、精神控制、必然获得喜爱 |
| 灵能 | 能够安全承载和输出的超自然力量规模 | 法术知识、施法技巧、超自然感官、神授权限 |

### 属性边界

- **体魄**同时提供一般性的力量、耐力、健康、抗性与恢复基准；力大体脆等罕见偏向由独立事实记录。
- **身手**只描述身体控制，不替代体力与专业训练。体魄提供动力，身手决定如何准确使用身体。
- **交涉**属于复合行动，与战斗、潜行、追逐和施法一样，不设为基础属性。
- **心性**描述自我稳定与坚持能力，不代表道德善恶、知识水平或目标正确。
- **魅力**描述自然形成印象和吸引注意的能力；颜值是重要来源，但不是魅力的全部。

## 三、统一数值档位

每十点构成一个独立档位，不合并记录。

| 数值 | 通用含义 |
| --- | --- |
| `1–9` | 尚未成熟、严重受损或极弱。 |
| `10–19` | 普通成年生命的常见范围。 |
| `20–29` | 经过训练、天赋较好或先天优于普通生命。 |
| `30–39` | 凡人精英、专业大师或明显强大的种族成员。 |
| `40–49` | 超越正常凡人上限。 |
| `50–59` | 英雄级、传奇凡人或稳定的超凡生命。 |
| `60–69` | 罕见强者、灾害级生物或大型超凡存在。 |
| `70–79` | 高阶超自然存在。 |
| `80–89` | 神话级存在，足以影响大型区域。 |
| `90–99` | 近神级存在，接近世界常规边界。 |
| `100+` | 神明、权柄、概念或法则级存在。 |

## 四、各项人物参照

下列人物只代表当前一项属性，不是完整模板。限定词属于例子本身：“体魄强大的古龙”不等于所有古龙全项强大，“天赋异禀的学徒”也不等于已经掌握高阶法术。

| 数值 | 代表人物或存在 |
| --- | --- |

| `30–39` | 专家学者、工程师、资深战略家、博学法师。 |
| `40–49` | 大师学者、顶尖发明家、一国级战略家。 |
| `50–59` | 改变时代知识体系的天才、伟大贤者、文明奠基者。 |
| `60–69` | 能推演文明系统的超级心智、古代思考构装体。 |

智识不等于知识。智识极高但从未学医的人仍然不会做手术，专业训练必须单独记录。

高心性只表示自我稳定和坚持能力，不表示善良、理智或目标正确。偏执的暴君也可能拥有极高心性。

| 数值 | 代表人物或存在 |
| --- | --- |
| `1–9` | 存在感被抹除者、表达与形象均严重受损者、令人本能回避的异常个体。 |
| `10–19` | 普通人族成年人、不特别引人注目的平民。 |
| `20–29` | 外貌出众者、演员、讨喜的年轻贵族、天生有亲和力的人。 |
| `30–39` | 宫廷名流、著名演说者、极具个人气质的领袖。 |
| `40–49` | 绝世美人、雄辩君主、极具威严的统帅。 |
| `50–59` | 凝聚时代运动的领袖、被万众追随的传奇人物。 |
| `60–69` | 拥有超自然吸引力的精魂、文明奠基者、传说中的魅惑生物。 |
| `70–79` | 散发神圣感的天使、极具诱惑力的大魔鬼、超自然使者。 |
| `80–89` | 大天使代言者、恶魔君王、神话中的绝美容貌者。 |
| `90–99` | 能令多个文明产生共同崇拜的近神化身、魅力型界外来客。 |

魅力不是“所有人都会喜欢”。审美、种族、文化、立场和个人经历仍会改变魅力的表现形式；高魅力也可以体现为威严、恐惧、神秘或危险的吸引力。

## 五、行动裁定

复合行动不设置独立属性，也不把多项属性简单相加或取平均。先根据角色采用的方法选择一个主要属性，其他属性与事实只作为条件、限制或辅助。

| 行动 | 可能涉及的因素 |
| --- | --- |
| 交涉 | 魅力形成印象，感知理解对方，智识组织理由，专业决定技巧；身份、关系与动机限定可能结果。 |
| 追逐 | 体魄提供持续能力，身手处理转向与障碍；体型、地形和移动方式同样重要。 |
| 战斗 | 正面压制偏体魄，精确闪避偏身手，预判偏感知；武器、训练和伤势不能被属性替代。 |
| 施法 | 灵能决定规模，智识帮助构建复杂术式，心性维持控制；法术知识和力量来源必须真实存在。 |
| 潜行 | 身手控制动作，感知寻找路线；环境、遮蔽物、装备和目标警戒决定可行性。 |
| 威慑 | 可以依赖魅力、体魄、身份、事实证据或特殊力量，取决于角色实际采用的方法。 |

这允许玩家自由选择做法。同一句“让守卫放行”，可以靠个人魅力、伪造公文、揭示秘密、展示武力或利用关系完成，不会被强制归入一个交涉数值。

## 六、属性之外的事实

七项属性提供默认能力。角色与默认情况存在重要偏差时，用事实直接记录，不再为每个例外增加新属性。

- **身体偏向**：力大体脆、耐力惊人、爆发强但不持久、动作笨重、精细灵巧。
- **外貌与形态**：俊美、威严、异族审美、伤疤、巨型身体、翅膀、水下呼吸。
- **专业与知识**：剑术、医学、航海、炼金、礼法、某国历史、龙语。
- **身份与关系**：爵位、声望、通缉、债务、亲疏、誓约、阵营。
- **装备与资源**：武器、护甲、工具、财富、补给、据点、军队。
- **状态与环境**：伤势、疲劳、饥饿、中毒、地形、天气、准备时间。
- **特殊能力与权限**：再生、免疫、读心、传送、预知、神授权柄、法则权限。
- **目标与动机**：愿望、恐惧、底线、忠诚与当前目的。

事实在对应场景中优先于宽泛属性。例如，“体魄很高但力大体脆”者仍能搬动巨石，却不能因此自动获得同等级的耐伤能力。

## 七、百科使用规则

- 本规则在百科中拆分为总则、七项属性和行动裁定九个条目，按当前行动选择性检索。
- 人物参照只说明当前属性，不是完整种族模板或职业模板。
- 新人物不因身份显赫而自动获得全项高值；每个高值都必须有体质、天赋、训练、经历或超凡本质作为依据。
- 普通背景人物可以先使用种族、年龄与职业所提供的数值区间；成为重要人物后，再将剧情已经确认的属性固定保存。
- 已经固定的属性不得为迎合单次剧情而临时改变。伤势、疲劳、装备、仪式和环境变化应记录为当前状态或事实。
