# Secret Fire 能力、法术与技法底层系统

> 状态：第一版运行框架已接入，完整行动裁定与能力成长尚未接入
> 定位：本文是内部玩法设计文档，不是玩家百科正文。
> 核心：统一规则、来源有别、无骰裁定、允许有边界的自由发挥。

## 一、系统解决什么问题

本系统不只处理魔法。凡是角色不能仅凭七项属性自然完成、需要学习、觉醒、授权、特殊身体或具体方法才能使用的能力，都由本系统记录。

包括但不限于：

- 法师学习的术式、神职者获得的神术、契约者借来的力量；
- 剑术招式、战斗姿态、反击、追踪、医术和潜行技巧；
- 龙息、夜视、再生、读心、飞行等血脉或种族能力；
- 炼金配方、符文制作、驯兽指令和机关操作；
- 武器、圣物、魔杖或其他物品授予的能力；
- 需要多人、材料、地点和时间才能完成的仪式。

系统必须同时守住两点：

1. 角色不能因为属性很高或玩家描述得漂亮，就临时拥有没有学会的能力。
2. 角色不应被一张僵硬的技能栏限制，只要行动处于已掌握能力的真实边界内，就允许改变目标、规模、表现与组合方式。

## 二、能力不是属性，也不是综合等级

三类信息分别回答不同问题：

| 信息 | 回答的问题 | 例子 |
| --- | --- | --- |
| 属性 | 角色能承载、感知或执行到什么规模 | 灵能 `34`、身手 `27` |
| 专业与能力 | 角色是否真的会这种方法 | 火焰塑形、剑术、外科医术 |
| 当前条件 | 这一次能否实际使用 | 双手是否空闲、是否有材料、是否受伤、是否能看见目标 |

高灵能不等于会法术，高身手不等于会剑术，高智识不等于掌握医学。反过来，角色即使学会高阶能力，如果属性、资源或权限不足，也只能使用其中较低规模的部分，或根本无法安全发动。

角色不设置“能力总等级”或“综合战力”。每项能力独立拥有来源、掌握状态与边界。

## 三、统一能力模型

所有能力记录分为四种形态。四种形态共用同一套事实门槛和行动裁定，但使用方式不同。

### 1. 专业

专业是长期训练或知识领域，不是一枚按下后发动的按钮。

例子：剑术、航海、医术、礼法、潜行、符文学、火焰学派、龙类知识。

专业的作用：

- 证明角色知道并会使用某类方法；
- 允许角色在该领域判断、临场变化和学习新技法；
- 在统一行动裁定中构成一项有效优势，或降低某项行动的事实门槛；
- 不能凭空提供超自然效果，也不能替代必要工具和权限。

### 2. 技法

技法是可以明确执行的一种方法，包括法术和武技。

例子：火焰箭、护盾术、缴械斩、盾牌反击、短距闪现、止血术、影步。

技法应描述一个能力范围，而不是只允许一句固定指令。例如“火焰箭”可以攻击火把、绳索或敌人，也可以降低输出用于照明；但它不能因为玩家换了形容方式就变成火墙、治疗术或城市级火灾。

### 3. 特性

特性是持续存在或由明确事件触发的能力，通常不需要主动发动。

例子：夜视、水下呼吸、火焰抗性、危险感知、再生、无法被普通毒素影响。

特性只在相关事件发生时读取，不在每个回合把所有被动能力交给 AI。特性也必须写明边界，例如夜视不等于看穿墙壁，火焰抗性不等于免疫熔岩。

### 4. 仪式

仪式是不能靠一次即时行动完成的能力。

例子：远距离传送、复生、解除古老诅咒、召唤大型存在、永久附魔、封闭位面裂隙。

仪式以时间、地点、材料、参与者、步骤和中断条件作为主要约束。仪式的难点不应简单压缩成一次属性比较；准备过程中的每个真实阻力分别裁定，最终是否成立由必要条件是否完整决定。

## 四、来源决定权限，不另造规则

能力来源不决定善恶，也不自动决定强弱。它主要说明能力如何获得、依靠什么存在、何时可能失效。

| 来源 | 获得方式 | 常见限制 |
| --- | --- | --- |
| 学习 | 导师、学院、书籍、长期研究 | 需要知识、记忆、练习与正确术式 |
| 训练 | 武艺、技巧、职业实践 | 依赖身体条件、工具与反复训练 |
| 天赋或血脉 | 出生、觉醒、身体结构 | 能力范围受血脉与形态限制 |
| 信仰或誓约 | 神明、圣职、誓言、共同信念 | 需要真实权限，可能受誓言边界约束 |
| 契约 | 妖精、魔鬼、精魂或其他授予者 | 条件、债务、撤回方式必须明确 |
| 灵魂与自然 | 精魂、土地、祖灵、自然循环 | 依赖关系、地点、季节或当地秩序 |
| 物品 | 武器、护符、魔杖、构装装置 | 必须持有、理解并满足物品使用条件 |
| 炼金与工艺 | 配方、材料、工具和制作过程 | 效果来自成品，制作本身需要时间与材料 |

同一种效果可以来自不同来源，但不会因此完全相同。法师的火焰术、龙的吐息和炼金火瓶都能制造火焰；它们在距离、准备、消耗、反制方式与社会认知上不同。

## 五、一项能力必须记录的内容

每项可执行能力只保存会影响实际判断的字段。

| 字段 | 含义 |
| --- | --- |
| 名称与稳定编号 | 名称可以有别称，编号保证系统不会把相似名称当成同一能力 |
| 形态 | 专业、技法、特性或仪式 |
| 来源 | 学习、训练、血脉、信仰、契约、自然、物品或工艺 |
| 功能标签 | 攻击、防护、移动、感知、隐匿、控制、恢复、变化、召唤、创造、交流或实用 |
| 已掌握效果 | 这项能力确定能够做到什么 |
| 明确边界 | 不能做到什么，不能被名称和描述绕过 |
| 使用前提 | 姿势、目标、距离、视线、语言、工具、材料、环境或权限 |
| 主要属性范围 | 根据具体用法可选择哪些主要属性，不把多项属性相加 |
| 规模要求与上限 | 最低承载要求，以及当前掌握程度允许的最大影响规模 |
| 发动方式 | 主动、反应、维持、被动或仪式 |
| 代价 | 体力、灵能负荷、专注、材料、时间、生命、关系或契约代价 |
| 持续与解除 | 何时开始、维持多久、怎样主动结束或自然失效 |
| 中断与反制 | 哪些现实方法可以阻止、躲避、抵抗、解除或破坏它 |
| 可观察表现 | 他人能看见、听见或事后调查到什么 |
| 掌握状态 | 初学、熟练或精通 |

不是每项能力都需要填满所有字段。水下呼吸不需要代价，剑术专业不需要持续时间，治疗仪式则可能需要几乎全部字段。

## 六、掌握程度只分三档

掌握程度不与属性重复，也不使用一百级熟练度。

| 状态 | 含义 |
| --- | --- |
| 初学 | 能按标准方式使用；复杂变化、恶劣环境与高压使用容易受阻 |
| 熟练 | 能稳定使用，并在已知边界内改变目标、节奏、表现或局部结构 |
| 精通 | 能进行困难组合、快速调整、教学、拆解与原创变体，但仍不能突破能力本身的领域和规模上限 |

“听说过”或“正在学习”不算已经拥有能力，应另记为知识或学习进度。掌握程度通常只构成权限或一项情境优势，不直接给属性增加数值。

## 七、规模与强度

魔法术式使用一至八环，作为术式复杂度、准备要求与影响范围的共同语言；武技、特性和普通专业不使用环阶。一至八环不等于角色等级、法术位、每日次数或伤害倍率。每次使用的实际规模仍沿用世界的 `1–100+` 能力标尺，并受三重上限约束：

1. **角色承载上限**：相关属性是否足够；大规模超自然输出通常由灵能决定。
2. **能力知识上限**：角色掌握的技法是否包含这种效果与结构。
3. **来源权限上限**：神授、契约、物品、血脉或地点是否允许这种规模。

三者取最低者。属性很高但只学会火焰箭的人，不能直接创造火焰风暴；完整掌握火焰风暴但灵能不足的人，也不能安全发动它。

系统内部可以为能力保存精确的最低要求和上限，玩家界面优先用自然语言表达：个人、小队、场景、区域、国度、世界。十点档位仍用于校准这些规模，不把数字机械地写入剧情。环阶告诉玩家“这种术式通常需要怎样的准备与承担”，并不能取代这三重判断。

能力可以主动降低规模。降低规模通常减少代价、可见度和附带破坏，但不会把效果转换成另一种能力。

## 八、代价不统一成一个蓝条

所有能力如果都消耗“法力值”，武技、信仰、契约和仪式会失去区别；如果每种能力又有独立点数，记录与计算会迅速膨胀。第一版采用“明确代价 + 少量负荷状态”。

### 1. 即时代价

- 消耗具体材料、弹药、药剂或物品充能；
- 占用一次当前行动或反应时机；
- 暴露位置、发出声光、留下魔法痕迹；
- 履行契约条款、引起法律或社会后果。

### 2. 累积负荷

只在真正需要时记录三类状态：

| 负荷 | 适用内容 | 建议阶段 |
| --- | --- | --- |
| 身体负荷 | 武技、奔跑、重击、身体变形 | 稳定、疲劳、透支、崩溃 |
| 专注负荷 | 精密技巧、心智能力、持续控制 | 稳定、分散、动摇、失控 |
| 灵能负荷 | 法术、神术、血脉输出、超自然维持 | 稳定、吃力、过载、枯竭 |

普通使用不必每次改变负荷。只有连续使用、超出舒适规模、带伤施展或能力明确写有沉重代价时才推进阶段。恢复来自休息、治疗、冥想、补给、履行条件或能力注明的方式，不按现实分钟计算冷却。

### 3. 极限使用

玩家可以在能力允许的领域内尝试超出当前安全上限，但不能凭此跨越不存在的知识或权限。极限使用必须在行动前具有可理解的严重风险，例如失控、昏迷、永久伤势、能力来源反噬或关系破裂。它不是免费提高数值的常规按钮。

## 九、维持、反应与准备

### 1. 维持

需要持续操控的法术、战斗姿态、心灵连接和召唤关系都属于“维持”。普通角色默认只能稳定维持一项主要能力；特殊训练或特性可以改变这一事实。

维持不会每回合自动消耗固定点数，但以下情况会触发重新判断：

- 角色受伤、失去意识或主动转移主要注意力；
- 环境突然改变，目标离开范围或能力来源被切断；
- 对手采取了专门破坏维持的行动；
- 角色同时尝试另一项互相冲突的复杂能力。

### 2. 反应

格挡、反制、瞬间护盾和危险闪避必须由场景中的真实时机触发。反应不是每轮固定刷新的一枚游戏币；角色只有在能察觉威胁、来得及行动且身体或能力可用时才能反应。

### 3. 准备

陷阱、预设符文、蓄力射击和埋伏会把时间、位置和暴露风险提前支付，从而改变后续行动的事实条件。准备形成决定性事实或情境优势，不储存一个抽象的“准备加成”。

## 十、组合、变体与自由发挥

自由度来自在边界内改变方法，而不是让 AI 临时发明能力。

### 允许的自由

- 改变已学技法的目标、角度、输出规模和持续方式；
- 用能力作用于环境，而不只作用于敌人；
- 将两项真实拥有的能力按现实顺序组合；
- 利用地点、材料、队友和目标状态改变阻力；
- 熟练或精通者在所属专业内进行合理变体。

### 不允许的越界

- 把火焰能力临时解释成治疗、传送或读心；
- 用高灵能替代从未学习的术式；
- 用多个低规模能力的形容词堆叠成世界级效果；
- 在同一次行动中无代价串联多个各自需要时间的步骤；
- 因为名称里有“神”“无敌”或“终极”就获得未记录的权限。

组合行动在第一个有意义的阻力处停止。不同能力不会把属性相加；如果组合真正改变了问题，就重建行动框架或形成一项决定性事实。

## 十一、能力如何参与统一行动裁定

一次使用能力的回合仍然遵循统一行动裁定：

1. 识别玩家目标、方法和实际使用的能力；
2. 验证角色是否拥有该能力，以及来源是否仍然有效；
3. 检查目标、距离、感知、工具、材料、姿势、权限与规模；
4. 根据本次用法选择一项主要属性；
5. 确定对手的相关阻力或环境门槛；
6. 应用二十点鸿沟与至多两个关键情境优势；
7. 锁定不可行、受阻、有限成功、完整成功或优势成功；
8. 锁定代价、负荷、持续状态和可观察后果；
9. 叙事者只能把已锁定结果写成剧情。

能力不会自动成功，也不会自动触发裁定。点亮一盏无人阻止的灯可以直接发生；在风暴中用同一术式点燃湿透的烽火，才可能需要裁定。

### 主要属性由方法决定

- 用纯粹力量扩大火焰规模：灵能；
- 在复杂法阵中精确重构术式：智识；
- 在受创和干扰中继续维持结界：心性；
- 用重剑技正面破开架势：体魄；
- 用剑尖挑落钥匙而不伤人：身手；
- 识破并抓住对方法术结构的短暂破绽：感知。

同一次行动只选择最主要的一项，其他属性不得相加。

## 十二、对抗、免疫与反制

系统不设置统一“豁免检定”。目标如何应对，取决于能力实际上怎样影响它。

| 效果 | 常见应对方式 |
| --- | --- |
| 飞行物或直线法术 | 躲避、掩体、格挡、打断施法者 |
| 精神侵入 | 心性、防护训练、距离、感知不到目标思想 |
| 身体束缚 | 体魄、身手、工具、破坏束缚来源 |
| 区域火焰 | 离开区域、隔绝燃料、防护、耐性 |
| 诅咒或契约 | 权限、真名、条款、仪式、解除来源 |
| 幻象 | 感知异常、验证事实、触碰环境、专门识破能力 |
| 持续法术 | 破坏维持、离开范围、反制来源、解除效果 |

免疫必须是明确事实，并写清免疫对象。免疫普通火焰不必然免疫神火，无法被读心也不等于不会受恐惧影响。

反制不是一句“我反制”就自动抹除能力。反制者必须能够察觉、理解或接触效果，并使用真实拥有的能力，在有效时机内面对相应阻力。

## 十三、伤害、治疗与控制的边界

在伤势系统正式设计前，本系统不为能力生成虚假的固定伤害数字。

- 攻击能力记录能够造成的伤害类型、规模、穿透条件和通常后果；
- 具体伤势由命中位置、防护、目标体魄、规模差距和现场事实决定；
- 治疗不能自动抹去已经成立的重伤，必须写清能止血、稳定、修复还是复生；
- 控制能力必须写明控制什么以及怎样解除，不能用“定身”“魅惑”概括无限权限；
- 即死、永久变形、复生、跨位面放逐等不可逆效果必须具有明确高阶权限与严格条件。

## 十四、学习、获得与成长

能力不能仅因为剧情需要由 AI 自动写入角色卡。新增能力必须有明确来源：

- 完成训练、研究或实战领悟；
- 获得导师、书籍、配方或传承；
- 血脉、身体或灵魂发生已经叙述的觉醒；
- 建立信仰、誓约或契约，并接受其真实条件；
- 装备具有该能力的物品；
- 完成足以改变能力边界的重大事件。

成长优先表现为：从正在学习变为初学、从初学变为熟练、扩大已掌握变体、降低特定代价、改善反制能力，或获得一项新技法。七项属性仍然缓慢成长，不能把频繁使用能力直接转换成属性点。

## 十五、百科、角色记录与生成规则

能力体系使用“基础分类 + 具体能力”两层结构，与物品系统的思想一致，但不要求百科列出世界上每一种招式。

百科负责记录：

- 四种能力形态及规则；
- 常见来源、功能领域和反制原则；
- 世界中广泛存在的学派、传统和标准能力；
- 稀有能力合理出现的组织、地点、传承与社会后果。

角色记录负责保存：

- 角色实际拥有的具体能力；
- 掌握状态、来源、已确认变体与当前有效性；
- 当前负荷、维持能力和暂时失效原因。

AI 可以为剧情提出新能力名称和表现，但必须先映射到稳定的形态、来源、功能和规模边界。无法映射或缺少来源的能力不能自动写入角色记录。

## 十六、低计算量运行方式

系统不在每轮读取角色的全部能力。

- 玩家明确提到能力名称时，按稳定编号读取该能力；
- 玩家描述方法而未说名称时，只在角色相关专业和当前可用技法中检索候选；
- 被动特性仅由对应事件标签触发，例如黑暗、毒素、坠落、读心或火焰；
- 当前维持能力始终进入场景状态，但不重复读取完整说明；
- 单次裁定最多读取与当前方法直接相关的少量能力、状态和反制事实；
- 普通 NPC 只生成当前场景实际使用的能力，成为重要人物后再固定保存。

这样，角色即使长期拥有数十项能力，一次回合通常也只处理一到三项。

## 十八、三个运行示例

### 1. 法师用火焰箭烧断吊桥绳索

- 角色拥有火焰箭，绳索在范围内且可见；能力允许点燃物体。
- 目标不是击败守卫，而是破坏绳索；阻力来自绳索粗细、潮湿程度和可用时间。
- 若绳索粗大潮湿，一次攻击可能只造成有限进展；玩家可以继续投入时间，但守卫也会行动。

### 2. 剑士尝试缴械巨人

- 剑士拥有缴械技法，但巨人的武器尺寸和体魄形成规模门槛。
- 普通缴械招式不能靠“精通”直接跨越二十点鸿沟。
- 若巨人的手已经受伤、武器卡在石缝中，问题发生改变，缴械才可能成立。

### 3. 牧师解除一项古老诅咒

- 驱散技法只能暂时压制表层效果；诅咒的根源系于未履行的誓约。
- 完整解除属于仪式，需要查明誓约、取得相关遗物并由有资格者见证。
- 高灵能可以帮助承载仪式，但不能替代真相、权限和必要步骤。

## 十九、第一版实现范围

当前已接入能力基础目录、角色已拥有能力记录、三类负荷与维持状态读取、只读人物卡，以及每轮最多三项的相关能力检索。六个跨类型样例用于验证统一结构，不会自动授予新角色。叙事模型不能直接把能力写入角色卡；能力学习、使用后的结果裁定和负荷自动变化仍需后续的统一行动裁定接管。

第一版只实现支撑实际游玩所需的最小闭环：

1. 能力基础目录：形态、来源、功能标签与共同边界；
2. 角色能力记录：稳定编号、掌握状态、来源、当前有效性；
3. 技法使用验证：拥有、前提、规模、代价、维持与反制；
4. 三类负荷状态，但只在显著消耗时更新；
5. 当前维持能力写入场景状态；
6. 新能力只能由已发生的剧情事件确认写入；
7. 玩家界面只显示已经拥有的能力卡，不提供自由修改器。

第一版暂不实现：庞大的预制法术清单、固定快捷栏、逐秒冷却、每招固定伤害、自动技能树、复杂连招计数和全世界 NPC 能力模拟。

## 二十、仍需共同决定的问题

1. 角色界面是否只展示已拥有能力，还是同时展示正在学习的能力进度；
2. 极限使用是否允许造成永久属性损伤，还是第一版只产生伤势与来源反噬；
3. 仪式是否需要独立的“准备清单”界面，还是先完全由剧情和场景状态承载；
4. 能力百科第一批应先覆盖哪些传统与常见能力，才能支撑真实开局；
5. 三类负荷是否在实际游玩中仍然过多，需要合并为更少的状态。

这些问题不影响统一模型成立。下一步应先用少量跨类型能力验证模型：一个攻击法术、一个防护法术、一个武技、一个被动特性、一个治疗能力和一个仪式；确认它们都能通过同一裁定流程运行，再扩充能力目录。
